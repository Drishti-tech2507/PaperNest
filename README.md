# 📚 PaperNest

PaperNest is a full-stack web application designed to help users explore books, research papers, and news in one place. It provides a seamless reading experience with authentication, personalized libraries, and email-based interactions.

---

## 🚀 Features

- 🔐 Authentication System
  - Register & Login
  - OTP-based password reset
  - Secure JWT authentication

- 📧 Email Integration
  - OTP verification emails
  - Welcome & Welcome-back emails

- 📚 Book Explorer
  - Search books using Google Books API
  - Read previews
  - Buy options with price comparison

- ❤️ Saved Library
  - Save books and content
  - View personalized collection

- 👤 User Profile
  - Avatar selection
  - Reading stats
  - Activity tracking

- 🎨 Modern UI
  - Built with Tailwind CSS
  - Smooth animations & clean layout

---

## 🛠 Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB (Mongoose)

### APIs & Services
- Google Books API
- Nodemailer (Email Service)

---

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

bash git clone https://github.com/Drishti-tech2507/PaperNest.git cd PaperNest 

---

### 2️⃣ Backend Setup

bash cd backend npm install 

Create a .env file inside backend/:

env MONGO_URI=your_mongodb_connection JWT_SECRET=your_secret_key EMAIL_USER=your_email@gmail.com EMAIL_PASS=your_app_password PORT=8000 

Run backend:

bash node server.js 

---

### 3️⃣ Frontend Setup

bash cd frontend npm install npm run dev
